## Pisi 0.10.0 Beta

0.9.0 Beta’dan sonraki ikinci beta sürümü. Bu sürüm Pisi’nin çalışma alanlarını sadeleştirir, map ve veri özelliklerini genişletir ve masaüstü arayüzünde kapsamlı kararlılık ile tema iyileştirmeleri içerir.

### Öne çıkanlar

- Node Properties sistemi geliştirildi; relation, rollup ve property şablonu akışları genişletildi.
- Bases tablo/kart görünümleri, filtreler ve sonuçlardan güvenli map üretme akışı geliştirildi.
- Map dışa aktarma, node yazı tipi/boyut tercihleri ve bağlantı etkileşimleri iyileştirildi.
- Sağ panel arama, Tags, Properties, Customize ve dock edilen takvim düzeni iyileştirildi.
- Workspace Center sadeleştirildi; Research, Team ve Plugins yüzeyleri kaldırıldı.
- Import/Export ile sürüm geçmişi ana arayüze taşındı; Project Integrity Settings altında toplandı.
- Light tema, ikonlar, toolbar ve map yüzeyleri daha tutarlı hale getirildi.
- Türkçe/İngilizce arayüz ve klavye kısayolu çevirilerindeki eksikler giderildi.
- Arama, project loading, map export, properties, tema ve sağ panel davranışları için yeni regresyon kontrolleri eklendi.

### Paketler

- Windows x64 Setup
- Windows ARM64 Setup
- Windows x64 Portable
- Windows ARM64 Portable
- `SHA256SUMS.txt`

### Bilinen sınırlar

- Bu sürüm beta olarak işaretlenmiştir.
- Windows paketleri henüz code-signed değildir; SmartScreen ilk çalıştırmada uyarı gösterebilir.
- macOS ve Linux paketleri bu sürümde yayımlanmıyor.
